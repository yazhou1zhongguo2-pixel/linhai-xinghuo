## 六、开发方法论沉淀（排障实录）

1. **数据认主**：云数据库记录必须有 `_openid` 归属。控制台导入=无主数据（改不动）→ 一律从小程序端创建；无主数据迁移 = 控制台删除 → 小程序重建
2. **undefined 进查询条件 = 匹配全部**：数据入口兜底编号 + 查询前拦截，双保险
3. **onLoad 只跑一次**：数据可能被别处改的页面，加载逻辑抽成统一函数，onLoad+onShow 都调
4. **权限有两套**：数据库权限（集合）与存储权限（文件）在控制台不同页面设置
5. **存储免费套餐**：仅创建者可读写且不可改 → 文件必须小程序内上传
6. **写后验证**：静默成功的 update 可能是空操作（无主数据）→ 写后读回比对
7. **真实设备先行**：模拟器≠真机（emoji 空白、canvas 偏移、字体差异）
