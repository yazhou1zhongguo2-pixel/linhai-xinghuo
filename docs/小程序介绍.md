## 一、这个项目是什么（1 分钟看懂）

**一句话**：一款"让消费者先看见林子、再信任产品"的森林生态农产品微信小程序。

**它解决什么问题**：深山里的木耳、灵芝、林下参——消费者凭什么相信它们是真的、安全的？答案不是广告，而是**透明**：把林地实况、生态数据、护林故事、产品全生命周期档案，全部真实展示出来，让信任自己长出来。

**核心设计理念**：
> 先感受这片林子的真实，再决定要不要带走它的一部分。

首页刻意**不设购买入口**——只讲三件事：林地影像、生态数据、护林故事。

## 二、怎么打开（3 分钟搞定）

1. **手机微信**扫码（正式上线后任何人可扫；上线前只有"体验成员"可打开）
2. 打开后看到底部 **5 个按钮**（tab）：首页 / 溯源 / 研学 / 认养 / 我的
3. 点底部按钮即可切换板块；页面内的卡片、按钮直接点击即可操作

**必知操作**：
- 点卡片 → 进入详情；左上角 ← 返回
- 底部 5 个 tab = 常驻导航，随时切换
- 演示时**用手机（真机）**，不要用电脑模拟器（观感差异大）

## 三、五大板块速览（每个板块是什么、能演示什么）

### 🏠 首页 —— "看见这片林子"
| 区块 | 内容 | 演示点 |
|---|---|---|
| 林地影像 | 无人机全景图+拍摄日期 | 视觉开场 |

### 🔍 溯源 —— "每一件产品都有它的来处"
扫码或点"体验档案" → **五维档案**：产地（真实 GPS 脱敏坐标）/ 生长记录 / 环境数据曲线 / 采收信息 / 检测报告（PDF 可下载）。带**防篡改标识**（档案编号+时间戳）。

### 🎓 研学 —— 三类课程预约
一日研学 / 三日深度营 / 五日科考营。详情含行程、课程、师资、评价。预约有**真实名额管控**（报名名额递减、满员拒绝、删单释放）。

### 🌳 云认养 —— 三档计划
199 木耳菌棒 / 1999 红松+中药材 / 19999 林下参（限量 50 株）。电子协议 → 专属认养主页（季度报告、碳汇趣味报告、续约提醒）。

### 👤 我的 —— 个人中心
订单 / 认养 / 研学 / 收藏 / 溯源记录 / 消息通知 / 联系客服。底部有**后台管理**入口（口令进入，管护员/管理员用）。

## 七、常见问题（演示现场可能被问）

**Q：数据是真的吗？**
A：架构与流程为真实系统（数据真实落云、真机验证）；当前展示内容为演示数据，正式运营接入驻场实测数据。

**Q：怎么盈利？**
A：本项目为大学生科创竞赛项目，现阶段以信任展示为主；取得企业主体后可接入真实支付与电商链路（架构已预留）。

**Q：为什么不用区块链做防篡改？**
A：成本与必要性权衡——档案编号+时间戳+云端存储已保证"记录可验证、环节可追问"；区块链是加分项而非必需项。

**Q：技术难点在哪？**
A：名额并发安全（数据库事务防超卖）、订阅消息链路（授权+推送）、跨端数据闭环（后台录入→前台档案自动更新）。

## 八、常见操作故障与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面空白/数据少 | 网络波动，回退了演示数据 | 等网络恢复后重进 |
| 订阅通知没到 | 未授权/一次性授权已用 | 重新走一次报名，点"允许" |
| 报名提示"名额已满" | 该日期真的满了 | 换日期（演示前选好充裕日期） |
| 后台进不去 | 口令错误 | 确认 linhai2026 |
