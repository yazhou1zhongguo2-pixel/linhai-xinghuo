## 三、踩坑清单（最有传播价值的素材）

1. **emoji 真机空白**：模拟器正常、安卓真机全空白 → 界面图标一律 PNG。*"你以为你写了，用户却什么都没看到"*
2. **图表在隐藏容器里画不出来**：canvas 在 display:none 时量不到尺寸 → 等容器可见再挂载
3. **undefined 进查询条件 = 删光全部数据**：收藏功能两次"取消一条删全部"事故 → 数据入口兜底+查询前拦截双保险
4. **无主数据改不动**：控制台导入的记录没有归属（_openid）→ 更新"静默成功但不变更" → 写后验证+数据认主迁移
5. **权限有两套**：数据库权限和存储权限在控制台不同页面；PDF 下载失败排查半天，最后是存储权限（免费套餐锁死，只能小程序内上传绕行）
6. **onLoad 只跑一次**：后台发了故事首页不显示，杀进程重进才出现 → onShow 刷新模式
7. **组件库三条依赖通道**：JS require / JSON usingComponents / WXML wxs，缺一报"component not found"
8. **标题不能当唯一标识**：两条同名故事导致收藏混淆 → 改用数据库 _id
9. **支付弹窗按钮不均分**：第三方组件内部布局 → 插槽接管自绘
10. **灰度基础库的坑**：canvas 偏移等怪癖 → 换稳定版
