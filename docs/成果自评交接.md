## 一、项目简介

为森林生态农产品（木耳/红松/林下参等）打造的**信任连接型微信小程序**。核心理念："先感受这片林子的真实，再决定要不要带走它的一部分"——首页不设购买入口，先展示林地实时影像、生态数据、护林故事，再引导溯源 / 研学 / 云认养。

**技术栈**：微信小程序原生框架（MINA）+ 微信云开发（云数据库/云存储，零服务器）+ ECharts + Vant Weapp。

**规模**：29 个页面 ｜ 16 个云数据库集合 ｜ 4 个云函数 ｜ 44 个自绘图标 ｜ 6 个 mock 数据模块 ｜ 2 个第三方组件库。
**版本**：v0.4（2026-08-04）——云函数体系（事务名额校验/订阅消息推送/数据自动汇聚）；开源：https://github.com/yazhou1zhongguo2-pixel/linhai-xinghuo

## 四、技术架构与关键决策（评估工程质量用）

1. **mock 先行 → 云数据库迁云**：`utils/api.js` 数据访问层统一出口，页面零改动完成数据源切换（"换引擎不换车"）
2. **云端优先 + 本地回退**：云不可用时 mock 兜底，控制台日志标注数据源
3. **脏数据防御**：数据入口统一兜底默认值（缺字段不崩）
4. **权限模型理解与应对**：数据库/存储两套权限、无主数据（_openid）识别与"数据认主"迁移、存储免费套餐限制的小程序内上传绕行
5. **生命周期治理**：onLoad 只跑一次 → onShow 统一刷新模式
6. **真实设备优先**：模拟器≠真机（emoji 空白、canvas 偏移、字体差异等 10+ 类排障经验，全部记录在开发历程.md）
7. **组件库集成**：echarts-for-weixin + Vant Weapp（依赖三通道：JS require / JSON usingComponents / WXML wxs）
