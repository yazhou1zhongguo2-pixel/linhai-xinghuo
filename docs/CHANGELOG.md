- **图标体系升级**：新增 13 个专属板块图标（订单/星星/时钟/铃铛/耳机/钢笔/脚印/新芽/篮子/相机/柱状图/标签/二维码）+ 11 个故事配图与认养专属图标（山雀/松鼠/野猪/溪流/晨光/初雪/落叶/菌棒/木耳菌棒/红松球果/林下参）
- 后台口令门（演示口令，正式版改云函数白名单）
- 样地位置/集合点定位（wx.openLocation 内置地图，免 key 免授权）
